# Cyber references and evidence

Connect observations to ATT&CK techniques, requirements, evidence and priorities when planning or reporting a security review.

Read the [shared contract](../cyber-audit/references/engagement.md). Start from the available evidence and permissions already established in the session. Load the method that addresses the question.

## Methods

| Method | Use |
|---|---|
| [Threat modeling](references/modules/threat-model.md) | Model threats for an architecture, service or planned change before the security review. |
| [Finding triage and reporting](references/modules/triage.md) | Verify scanner findings, reject false positives and write an evidence-based security report. |
| [Security research](references/modules/research.md) | Find current vendor advisories, standards, research and tools for a specific security question. |

Read the [domain guide](references/domain.md) for tool selection and handoffs. Bundled third-party references do not authorize tool execution.

Report findings with the [evidence template](../cyber-audit/references/finding-template.md), separating verified coverage, hypotheses and untested checks.
