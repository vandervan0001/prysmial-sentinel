# Finding template

Complete each field from the observations:

- Stable identifier and a title naming the defect.
- Evidence status and proposed severity, with justification.
- Asset, environment, commit or version, file and line numbers.
- Controlled input, actor and preconditions.
- Path to the sensitive effect and existing checks.
- Minimal, reproducible, sanitized evidence; identify static review versus execution.
- Control case and attempt to disprove the finding.
- Observed impact and potential impact, recorded separately.
- Targeted correction, side effects and responsible owner.
- Regression test, before/after result and fix reference.
- CWE reference or versioned requirement checked against the source.
- Limits and information still needed.

A screenshot or HTTP status alone does not establish account, object and state context. A `403` returned for an already expired token does not verify access control on the object.
